I am a **Software Engineer** specializing in **scalable backend architectures, distributed systems, and production AI platforms**. My focus centers on designing systems that remain predictable, observable, and resilient under real-world traffic.

From engineering sub-250ms vector retrieval pipelines across 10,000+ records to implementing cache-aside strategies that slash primary database load by ~30%, I design software where performance, fault tolerance, and clean architecture are first-class citizens.
